# 异步流水线性能测试 - 使用指南

## 📋 功能说明

测试**原生 Torch 异步流水线**的性能，重点分析**序列化/反序列化的时间占比**。

**流水线架构：**
```
GPU Tensor
    ↓
[D2H Worker] → GPU→CPU 传输 + 序列化
    ↓
[Exchange Worker] → 分布式通信 + 序列化
    ↓  
[XOR Worker] → 按位异或计算
```

## 🎯 关键发现

### **1. 序列化是主要瓶颈**

- **D2H 阶段**: 90-95% 是序列化/反序列化
  - D2H 传输本身很快（< 5 ms）
  - 序列化非常慢（10-30 ms）
  
- **Exchange 阶段**: 95-100% 是序列化
  - 单 rank 测试无通信开销
  - 多 rank 测试会有额外通信时间
  
- **XOR 阶段**: 60-70% 是反序列化
  - XOR 计算很快（~2 ms）
  - 但反序列化仍需 4-6 ms

### **2. 整体序列化开销**

- **总体占比**: 通常 **80-90%** 的时间用于序列化
- **计算占比**: 只有 **10-20%** 是真正的计算
- **优化潜力**: 巨大！消除序列化可提升 5-10x

### **3. 异步流水线优势**

- **加速比**: 1.5-2.5x（取决于 tensor 数量）
- **并行度**: 3 个阶段可以同时处理不同 tensor
- **效率**: 隐藏了大部分串行等待时间

## 🔧 故障排查

### **问题 1: Worker 进程无法启动**

**症状：** 看到 "警告: 只有 X/3 个 worker 就绪"

**解决：**
- 检查 CUDA 是否可用
- 检查分布式环境配置（MASTER_ADDR, MASTER_PORT）
- 查看错误日志

### **问题 2: 流水线卡住**

**症状：** "等待超时，已完成 0/3 个 tensor"

**解决：**
- 检查 D2H Worker 是否收到数据
- 检查是否有异常被捕获
- 增加调试输出

### **问题 3: 分布式初始化失败**

**症状：** "Exchange Worker: 分布式初始化失败"

**解决：**
- 确保两个 rank 使用相同的 MASTER_PORT
- 确保网络可达（localhost 或实际 IP）
- 检查防火墙设置
